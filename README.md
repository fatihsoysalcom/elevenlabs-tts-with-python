# ElevenLabs TTS with Python

This Python script demonstrates how to use the ElevenLabs v3 Text-to-Speech API to generate audio from text. It shows how to make an API request with your key and save the resulting audio file.

## Language

`python`

## How to Run

1. Install the 'requests' library: pip install requests
2. Set your ElevenLabs API key as an environment variable: export ELEVENLABS_API_KEY='YOUR_API_KEY'
3. Run the script: python main.py
